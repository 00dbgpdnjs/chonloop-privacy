촌한바퀴 개인정보처리방침

시행일: 2026년 8월 16일

유혜원(이하 “운영자”)은 촌한바퀴(ChonLoop)(이하 “앱”) 이용자의 개인정보를 중요하게 생각하며, 관련 법령에 따라 개인정보를 안전하게 처리하기 위해 본 개인정보처리방침을 안내합니다.

본 방침은 현재 공개된 앱 버전을 기준으로 작성되었습니다. 앱의 기능, 외부 서비스 또는 데이터 처리 방식이 변경되면 본 방침도 변경될 수 있습니다.

1. 처리하는 개인정보 및 수집 방법

앱은 회원가입이나 별도 계정 생성을 요구하지 않습니다. 앱 이용 과정에서 다음 정보가 처리될 수 있습니다.

  • 위치정보: 현재 위치를 이용한 코스 검색·생성 및 지도 표시를 위해 기기의 정확한 위치정보를 처리할 수 있습니다. 사용자가 직접 장소를 검색하거나 선택한 경우 선택한 장소의 좌표와 주소도 처리될 수 있습니다.
  • 산책 기록: 산책 경로, 출발·도착 위치 또는 주소, 이동 거리, 소요 시간, 방문 장소, 완주 기록 및 지도 이미지가 기기에 저장될 수 있습니다.
  • 사용자 입력 정보: 앱에서 닉네임, 평점 또는 리뷰를 입력하는 기능이 사용되는 경우 해당 정보가 처리될 수 있습니다.
  • 오류·기기 정보: 앱의 안정성 확인을 위해 앱 버전, Android 버전, 오류 내용 등 진단 정보가 기기의 로그에 일시적으로 기록될 수 있습니다. 현재 버전은 별도 분석 서버로 진단 정보를 전송하지 않습니다.

위치정보는 Android 운영체제의 권한 요청 후 사용자가 권한을 허용한 경우에만 이용합니다. 권한을 허용하지 않아도 일부 기능은 기본 위치 또는 장소 검색으로 이용할 수 있으나, 현재 위치 기반 기능은 제한될 수 있습니다.

2. 개인정보 처리 목적

  • 현재 위치 표시 및 주변 장소 검색
  • 산책 코스 생성 및 보행 경로 안내
  • 장소 상세 정보와 지도 기능 제공
  • 산책 완료 기록과 사용자 입력 정보의 기기 내 저장
  • 앱 오류 확인 및 서비스 안정성 개선

3. 개인정보의 외부 전송 및 제공

앱은 기능 제공에 필요한 범위에서 위치 좌표, 검색어 또는 경로 좌표를 다음 외부 서비스에 요청 데이터로 전송할 수 있습니다. 운영자는 해당 정보를 광고 목적이나 이용자 식별 목적으로 판매하지 않습니다.

  • 카카오 Local API 및 카카오 지도 SDK: 장소 검색, 지도·장소 기능 제공
  • 한국관광공사 관광정보 Open API: 주변 관광지 및 장소 정보 제공
  • SK텔레콤 T map API: 보행 경로 생성 기능 제공
  • OpenRouteService: 보행 경로 생성 기능 제공

외부 서비스의 처리 방식, 보관 기간 및 서버 위치는 각 제공자의 정책과 서비스 조건에 따릅니다. 외부 API의 기능을 사용하면 요청 데이터가 국외 서버에서 처리될 수 있으므로, 이용자는 해당 서비스 이용에 동의하지 않을 경우 관련 기능 사용을 중단할 수 있습니다.

4. 개인정보의 보관 및 파기

  • 산책 기록, 닉네임 및 앱 사용 중 생성된 일부 정보는 앱의 로컬 저장공간에 저장되며, 이용자가 앱 데이터를 삭제하거나 앱을 삭제하면 기기에서 삭제될 수 있습니다.
  • 앱이 외부 API에 전송한 요청 데이터의 보관 및 파기는 각 외부 서비스 제공자의 정책에 따릅니다.
  • 운영자가 이메일 문의를 통해 개인정보를 받은 경우, 문의 처리에 필요한 기간 동안 보관한 뒤 관련 법령상 보존이 필요한 경우를 제외하고 지체 없이 삭제합니다.

5. 이용자의 권리와 행사 방법

이용자는 자신의 개인정보 처리에 관해 문의하거나 정정·삭제·처리 제한을 요청할 수 있습니다. 기기에 저장된 산책 기록은 Android 설정의 앱 저장공간에서 앱 데이터 삭제 또는 앱 삭제를 통해 직접 삭제할 수 있습니다. 권리 행사나 개인정보 관련 문의는 아래 이메일로 연락해 주세요.

6. 개인정보의 안전성 확보 조치

  • 외부 API 통신 시 HTTPS 등 암호화된 전송 구간을 사용하도록 운영합니다.
  • 앱에 필요한 정보만 처리하고, 위치 권한은 기능 사용 시 운영체제를 통해 요청합니다.
  • 운영자는 개인정보 접근 권한과 외부 서비스 설정을 정기적으로 점검합니다.

7. 아동의 개인정보

앱은 아동을 주된 이용 대상으로 기획되지 않았습니다. 보호자는 아동의 앱 이용과 개인정보 제공 여부를 확인해 주시기 바랍니다.

9. 개인정보처리방침의 변경

법령, 서비스 또는 앱 기능의 변경에 따라 본 개인정보처리방침을 수정할 수 있습니다. 변경 시 이 페이지에 시행일과 변경 내용을 표시합니다.
